# ticktasker

TickTasker — finish one meaningful thing a day. A minimalist to‑do app with a Daily Highlight, a Commitment Slider (0→3), the Two‑Day Rule, a Two‑Minute Tasks filter, and a Study → Write pipeline so you capture ideas, turn them into posts, and ship—without burnout.
