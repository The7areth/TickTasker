# Contributing to TickTasker

Thanks for considering a contribution.

## Ground rules

- Keep changes focused and easy to review.
- Align changes with the core product direction: one meaningful thing per day.
- Avoid speculative feature bloat.

## Before opening a PR

Run from repository root:

```bash
dart format .
flutter analyze
flutter test
```

## Pull request expectations

Please include:

- What changed
- Why it changed
- How it was tested
- Any follow-up work not included

## Reporting bugs and feature ideas

Use issue templates in `.github/ISSUE_TEMPLATE/` so reports include enough context.
