# Application walkthrough

1. Open TickTasker. A new workspace starts empty, with a prompt to add a task.
2. Select **Add task**, enter “Prepare project walkthrough,” set commitment to **Now**, and estimate 25 minutes. Save it.
3. Add “Send meeting agenda,” with a two-minute estimate.
4. Star the walkthrough task. It moves to the top and receives a **Daily highlight** label.
5. Select **≤ 2 minutes** to find the agenda task. Clear the filter to see both tasks again.
6. Search by part of a task title. Search is case-insensitive and combines with the filters.
7. Complete the highlighted task using its checkbox. Open **Completed** to inspect it or reopen it.
8. Choose **Edit** from a task's options. Change its title, commitment, or estimate. Clear the estimate to remove it.
9. Reload the app. Saved tasks, completion states, and today's highlight remain on the same device/browser profile.
10. Choose **Delete** from task options and confirm to remove a task.

An empty title or an invalid time estimate receives a form-level explanation. Estimates accept whole minutes between 1 and 1440. Titles support up to 200 characters.

The application follows the system's light/dark appearance. At narrow widths, filters wrap and the task list scrolls.
